================================================================================
1. PROJECT OVERVIEW
================================================================================
- Project Name: PetConnect
- Architecture: MERN Stack Monorepo (MongoDB, Express, React 18, Node.js)
- Goal: Full-stack web application connecting Pet Owners (Users), Pet Caretakers, 
  and Platform Administrators with real-time social & service features.
- Core Modules:
  1. Pet Marketplace (List pets for sale/adoption, browse, buy, verify listings)
  2. Caretaker Services (Apply to be a caretaker, professional showcase profile, 
     set rates/services, accept/reject service bookings)
  3. Real-Time Chat & Connections (Connection requests, Socket.io 1-on-1 chat, 
     media sharing, typing indicators, read receipts, unread badge notifications)
  4. Administrative Platform (User management, caretaker application approval, 
     pet verification, caretaker profile draft side-by-side review)

================================================================================
2. TECH STACK & CONFIGURATION
================================================================================
Backend:
- Node.js (ES Module system "type": "module")
- Express.js v4.21.2
- Socket.io v4.8.1 (Real-time WebSockets with JWT authentication)
- Database: MongoDB with Mongoose ORM v8.13.0
- Auth: JWT (jsonwebtoken v9.0.2) + Passwords hashed with bcrypt v5.1.1 + Google OAuth
- Middlewares: cookie-parser, body-parser, cors
- Media Uploads: Multer + DataURI + Cloudinary v2.6.0
- Server Entry: server.js
- Default Port: 7001 (or process.env.PORT)

Frontend:
- React 18 SPA (Single Page Application)
- Vite Build System
- Routing: react-router-dom v6
- State Management: React Context API (AuthContext, AdminContext)
- Styling: Tailwind CSS + Vanilla CSS
- Sockets: socket.io-client
- Entry Point: src/main.jsx & src/App.jsx

4. DATABASE MODELS
================================================================================
1. User Schema (userModel.js): name, email, password, mobile, address, role, lastSeen.
2. CaretakerApplication Schema (caretakerApplicationModel.js): applicant, experience, skills, rate, status.
3. CaretakerProfile Schema (caretakerProfileModel.js): version, status, headline, rates, services, gallery, homeEnvironment.
4. PetOrder Schema (petModel.js): category, breed, price, image, isApproved, soldBool, owner, buyer.
5. BookingRequest Schema (bookingRequestModel.js): user, caretaker, service, date, hours, totalCost, status.
6. ConnectionRequest Schema (connectionRequestModel.js): requester, recipient, status.
7. Conversation Schema (conversationModel.js): participants, lastMessage.
8. Message Schema (messageModel.js): conversationId, sender, text, image, readBy.
9. Notification Schema (notificationModel.js): user, sender, type, title, message, read.
