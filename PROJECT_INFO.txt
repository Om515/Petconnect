1. PROJECT OVERVIEW
================================================================================
- Project Name: PetConnect
- Architecture: MERN Stack Monorepo (MongoDB, Express, React 18, Node.js)
- Goal: Full-stack web application connecting Pet Owners (Users), Pet Caretakers, 
  and Platform Administrators with real-time social & service features.
- Core Modules:
  1. Pet Marketplace (List pets for sale/adoption, interactive creation preview wizard, browse, buy, verify listings)
  2. 🤖 AI Pet Scanner (Powered by Google Gemini 3.5 Flash Vision AI with guest rate limiting for breed identification, health risks, compatibility, & market insights)
  3. Caretaker Services (Apply to be a caretaker, professional showcase profile, draft versioning engine, set rates/services, accept/reject service bookings)
  4. Real-Time Chat & Connections (Connection requests handshake, Socket.io 1-on-1 chat, media sharing, typing indicators, read receipts, unread badge notifications)
  5. Administrative Platform (User management, caretaker application approval, pet verification, caretaker profile draft side-by-side review)

2. TECH STACK & CONFIGURATION
================================================================================
Backend:
- Node.js (ES Module system "type": "module")
- Express.js v4.21.2
- AI Engine: @google/generative-ai (gemini-3.5-flash)
- Rate Limiting: express-rate-limit v7.5.0
- Socket.io v4.8.1 (Real-time WebSockets with JWT authentication)
- Database: MongoDB with Mongoose ORM v8.13.0
- Auth: JWT (jsonwebtoken v9.0.2) + Passwords hashed with bcrypt v5.1.1 + Google OAuth
- Middlewares: aiRateLimiter.js, isAuth.js, caretakerIsAuth.js, isAdmin.js, authenticate.js, multer.js, cookie-parser, body-parser, cors
- Media Uploads: Multer + DataURI + Cloudinary v2.6.0
- Server Entry: server.js
- Default Port: 7001 (or process.env.PORT)

Frontend:
- React 18 SPA (Single Page Application)
- Vite Build System
- Routing: react-router-dom v6
- State Management: React Context API (AuthContext, AdminContext)
- Styling: Tailwind CSS + Vanilla CSS
- Iconography & UI: lucide-react, framer-motion, react-hot-toast
- Sockets: socket.io-client
- Entry Point: src/main.jsx & src/App.jsx

4. API ROUTE MAPPING
================================================================================
AI Scanner Routes:
- POST /api/ai/scan-guest  -> Guest AI Scanner (Rate Limited: max 5 req/15 min)
- POST /api/ai/scan-auth   -> Authenticated AI Scanner (Unlimited)

Auth Routes:
- POST /api/auth/register
- POST /api/auth/login
- POST /api/auth/google
- POST /api/auth/forgot-password

User Routes:
- GET  /api/user/buy-pet
- POST /api/user/sell-pet
- POST /api/user/book-pet
- POST /api/user/wishlist/toggle
- GET  /api/user/wishlist

Caretaker Routes:
- POST /api/caretaker/apply
- POST /api/caretaker/professional-profile
- GET  /api/caretaker/my-profile

Chat & Socket Routes:
- POST  /api/chat/requests (Send Connection Request)
- PATCH /api/chat/requests/:id/respond (Accept/Reject Connection)
- GET   /api/chat/conversations
- GET   /api/chat/messages/:conversationId
- POST  /api/chat/messages

Admin Routes:
- GET  /api/admin/display-users
- GET  /api/admin/get-pet-list
- POST /api/admin/approve-pet
- GET  /api/admin/get-caretaker-list
- POST /api/admin/approve-caretaker
- GET  /api/admin/caretaker-profiles/pending
- POST /api/admin/caretaker-profiles/approve
- POST /api/admin/caretaker-profiles/reject
